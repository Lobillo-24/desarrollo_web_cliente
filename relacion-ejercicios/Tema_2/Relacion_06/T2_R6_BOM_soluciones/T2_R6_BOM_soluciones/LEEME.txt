Soluciones de T2_R6-BOM

Abre index.html para navegar por los ejercicios.

Los archivos están separados por ejercicio para que sea fácil revisarlos y entregarlos por partes.
No se ha añadido una hoja de estilos. Solo se utiliza el atributo border en las tablas para que los datos se vean separados.

Notas:
- En el enunciado del ejercicio 3 no aparece el apartado e), así que se han mantenido las letras originales.
- El navegador puede bloquear ventanas emergentes. Si un enlace no abre una ventana, permite las ventanas emergentes para estos archivos.
- Los métodos para mover o redimensionar ventanas pueden estar limitados por el navegador.
- document.anchors cuenta anclas antiguas que usan name; por eso el ejemplo usa <a name="...">.
